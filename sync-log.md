# My Git and GitHub Synchronization Log

## 1. Commands I used

- `git status` — Checked the status of my local repository.
- `git remote -v` — Checked which GitHub repository was connected.
- `git ls-remote origin` — Tested the connection to GitHub.
- `git add git-practice.md` — Added my new file to the staging area.
- `git commit -m "Add Git practice notes"` — Created a local commit.
- `git push origin main` — Uploaded my commit to GitHub.
- `git pull origin main` — Downloaded and integrated changes from GitHub.

## 2. What worked well?

I successfully connected my local repository to GitHub.

I learned how to create a file, stage it, commit it, and push it to GitHub.

I also learned how to make changes directly on GitHub and synchronize them with my local repository using git pull.

## 3. What problems did I experience?

At first, I received the error "rejected (fetch first)" when trying to push my commits.

I learned that this can happen when GitHub contains changes that are not available in my local repository.

I also learned how to check my repository status and remote connection.

## 4. What did I learn?

- `git add` prepares changes for a commit.
- `git commit` saves changes in the local Git history.
- `git push` sends commits to GitHub.
- `git pull` downloads and integrates changes from GitHub.
- `git status` helps me check the current state of my repository.

I now understand better how my local repository and GitHub work together.
